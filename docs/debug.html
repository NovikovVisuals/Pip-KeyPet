Почему такое настроение

1. Спит?→ asleep
2. Редкая карточка (stoned / pinkeye, примерно раз в месяц)
3. Тело: батарея без зарядки
4. Послевкусие недавнего события
5. Какая нужда ниже своей черты сильнее всех
6. Ночь (22–6) и энергия < 0.5?→ sleepy
7. Чем занят: проснулся, гуляет, на зарядке
8. Как в целом живётся (валентность) → палитра дня
Поверх этого — реакции на секунды: погладили, тычки (angry → furious → rage → swearing), тряска, подули, громкий звук, уронили, вверх ногами, знакомство (love / shy / suspicious / angry / belligerent), звонок (yes / no / puzzled), игры, кормёжка.
